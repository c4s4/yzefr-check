# YZEfr Check

Validate Markdown files for <yearzeroengine.fr> site.

## Installation

### Unix users (Linux, BSDs and MacOSX)

Unix users may download and install latest *yzefr-check* release with command:

```bash
sh -c "$(curl https://sweetohm.net/dist/yzefr-check/install)"
```

If *curl* is not installed on you system, you might run:

```bash
sh -c "$(wget -O - https://sweetohm.net/dist/yzefr-check/install)"
```

**Note:** Some directories are protected, even as *root*, on **MacOSX** (since *El Capitan* release), thus you can't install *yzefr-check* in */usr/bin* for instance.

### Binary package

Download the archive on
[the releases page](https://github.com/c4s4/yzefr-check/releases). Unzip it and
put the binary for your platform somewhere in your *PATH* (in directory
*/usr/local/bin* for instance).

*Enjoy!*
